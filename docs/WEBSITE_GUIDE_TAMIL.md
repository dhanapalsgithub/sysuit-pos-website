## 4. படிவங்கள் எப்படி வேலை செய்கின்றன (Forms)

### அ) தொடர்பு படிவம் (Contact Form)
புலங்கள்: பெயர், மின்னஞ்சல், தொலைபேசி, நிறுவனம் (விருப்பம்), செய்தி.

- "Send Message" பொத்தானை அழுத்தினால், தகவல் `POST /api/contact`
  என்ற முகவரிக்கு அனுப்பப்படும்.
- தவறான/காலியான புலங்கள் இருந்தால் சிவப்பு நிற பிழை செய்தி காண்பிக்கப்படும்.
- வெற்றி பெற்றால் பச்சை நிற அறிவிப்பு (toast) தோன்றும், படிவம் காலியாகும்.
- தகவல் PostgreSQL-ல் `contacts` அட்டவணையில் சேமிக்கப்படும்.

### ஆ) கேள்வி கேட்கும் படிவம் (Ask a Question)
புலங்கள்: பெயர், மின்னஞ்சல், வகை (Category), தலைப்பு, கேள்வி.

- "Submit Question" பொத்தான் தகவலை `POST /api/inquiries`-க்கு அனுப்பும்.
- தகவல் PostgreSQL-ல் `inquiries` அட்டவணையில் சேமிக்கப்படும்.

> குறிப்பு: அனைத்து தகவல்களும் சர்வர் பக்கத்தில் (backend) சரிபார்க்கப்படும்
> (validation) — காலி பெயர், தவறான மின்னஞ்சல் போன்றவை நிராகரிக்கப்படும்.

## 5. சேவை விவரப் பக்கங்கள் (Service Detail Pages)

முகவரி வடிவம்: `/services/<slug>` — எடுத்துக்காட்டு: `/services/health-it`.

ஒவ்வொரு பக்கத்திலும்:
- சேவையின் தலைப்பு, விளக்கம், படம்
- "What's included" — உள்ளடங்கிய அம்சங்கள் பட்டியல்
- "Key benefits" — முக்கிய நன்மைகள்
- "Explore other services" — மற்ற சேவைகளுக்கான இணைப்புகள்

தவறான முகவரி (இல்லாத சேவை) கொடுத்தால் "Service not found" பக்கம் காண்பிக்கப்படும்.

7 சேவைகளின் slug பட்டியல்:
`health-it`, `website-design`, `web-development`, `digital-marketing`,
`mobile-apps`, `pos-application`, `erp-solutions`.

## 6. நிர்வாக பக்கம் (Admin Dashboard) — `/admin`

- மொத்த சமர்ப்பிப்புகள், Contact செய்திகள், கேள்விகள் ஆகியவற்றின்
  எண்ணிக்கையை அட்டைகளாக காட்டும்.
- "Contacts" மற்றும் "Questions" எனும் இரு தாவல்கள் (tabs).
- "Refresh" பொத்தான் மூலம் புதிய தகவல்களை மீண்டும் ஏற்றலாம்.
- இது `GET /api/contact`, `GET /api/inquiries`, `GET /api/stats`
  ஆகியவற்றிலிருந்து தரவை எடுக்கிறது.

## 7. தரவு எங்கே சேமிக்கப்படுகிறது?

அனைத்து படிவத் தகவல்களும் **PostgreSQL** தரவுத்தளத்தில் (`sysuit`)
சேமிக்கப்படுகின்றன. இதை **pgAdmin 4** மென்பொருள் மூலம் பார்க்கலாம்
(விவரங்களுக்கு `PGADMIN4_SETUP.md` ஆவணத்தைப் பார்க்கவும்).

அட்டவணைகள்:
- `contacts` — தொடர்பு படிவத் தகவல்கள்
- `inquiries` — கேள்வி படிவத் தகவல்கள்

## 8. இணையதளத்தை உள்ளூரில் இயக்குவது (Local Run)

```bash
yarn install     # தேவையான தொகுப்புகளை நிறுவவும்
```
